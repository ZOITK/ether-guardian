## 1. 개요 (Overview)

**영토 시스템**은 게임의 **핵심 경쟁 메커니즘**입니다. 플레이어가 몬스터를 제거한 지역에 **에테르 추출기(Ether Extractor)**를 설치하여 영토를 점유하고, 자동 터렛을 배치하여 다른 플레이어의 침략을 방어합니다.

**핵심 루프**:
```
몬스터 제거 (정화)
    ↓
추출기 설치 (점유)
    ↓
에테르 수집 (자원 축적)
    ↓
터렛 배치 (방어)
    ↓
침입 방어 (PvP)
```

---

## 2. 플레이어 판타지 (Player Fantasy)

- **영토 주인의 감각**: 정화한 지역이 '나의 것'이라는 소유감
- **진지 강화의 성취감**: 터렛을 배치하고 침입을 막은 경험
- **전략적 선택**: 어디에 진지를 지을지, 얼마나 강화할지 결정
- **경제 순환**: 에테르 수집 → 강화 → 더 큰 영토 → 더 많은 자원
- **다른 플레이어과의 긴장**: "내 진지를 언제 쳐들어올까?" 불안감

## 3. 상세 규칙 (Detailed Rules)

### 3.1 에테르 추출기 (Ether Extractor)

**기본 사양**:
- **설치 조건**: 정화된 지역 (몬스터 제거 후 30초 이내)
- **효과 반경**: GPS 기반 반경 100m
- **에테르 수집**: 초당 10 에테르 (기본)
- **설치 비용**: 무료 (최초)
- **내구도**: 100 HP (몬스터/플레이어 공격으로 피해)

**상태**:
```
Vacant (무주인)
  ├─ 다른 플레이어 설치 가능
  └─ 자동 몬스터 스폰 (매 30초)

Claimed (점유)
  ├─ 소유자만 강화 가능
  ├─ 터렛 활성화
  └─ 에테르 수집 활성화

Under Attack (침략 중)
  ├─ 침입자 방어 터렛 발동
  ├─ 소유자에게 알림
  └─ 방어 승리 시 침입자 추방
```

### 3.2 방어 터렛 (Defense Turret)

**터렛 사양**:
- **설치 비용**: 500 에테르
- **효과 범위**: 반경 50m
- **공격 능력**:
  - 대미지: 25 HP/발
  - 재사용 대기시간: 2초
  - 정확도: 90% (거리에 따라 감소)
- **에너지 소비**: 초당 5 에테르
- **내구도**: 50 HP
- **최대 설치**: 5개 (한 진지당)

**자동 사격 로직**:
```gdscript
# 터렛 AI (의사코드)
func _process_turret_ai(delta: float):
    # 1. 사정거리 내 적 감지 (몬스터 또는 적 플레이어)
    var targets = get_targets_in_range(50.0)
    
    # 2. 가장 가까운 적 선택
    var target = targets.min_by(func(t): return global_position.distance_to(t.position))
    
    # 3. 쿨다운 확인
    if fire_cooldown <= 0 and target:
        # 4. 발사 (정확도 90%)
        if randf() < 0.9:
            fire_projectile(target)
            fire_cooldown = 2.0
            energy_consumed += 5.0
    
    fire_cooldown -= delta
```

### 3.3 영토 점유 규칙 (Territory Claim)

**점유 조건**:
1. 몬스터 제거 완료
2. 정화된 지역 (30초 유지)
3. 추출기 설치 (GPS 클릭)

**점유 권리**:
- 설치 플레이어 = 소유자
- 소유자만 터렛 배치, 강화 가능
- 다른 플레이어는 점유 지역 침입 가능 (침략)

**영토 크기와 우선순위**:
```
반경 100m = 한 추출기의 영토
  ├─ 겹침 가능 (다른 플레이어와)
  │   └─ 겹친 지역에서 충돌 (PvP)
  └─ 강화 가능 (추가 터렛, 벽, 함정)
```

### 3.4 진지 강화 (Base Upgrade)

**강화 옵션**:

| 강화 | 비용 | 효과 | 최대 레벨 |
|------|------|------|---------|
| 터렛 추가 | 500 에테르 | 방어력 +25 HP | 5개 |
| 에테르 수집 +10% | 1000 에테르 | 수집률 +1 에테르/초 | 5레벨 |
| 추출기 HP +20 | 300 에테르 | 내구도 +20 HP | 5레벨 |
| 빠른 재장전 | 800 에테르 | 터렛 쿨다운 -0.5초 | 3레벨 |
| 범위 확장 +10m | 1200 에테르 | 반경 +10m | 3레벨 |

**강화 전략**:
- 초기: 터렛 2-3개 배치 (기본 방어)
- 중기: 에테르 수집 강화 (자원 순환)
- 후기: 범위 확장 + 터렛 추가 (영토 확대)

### 3.5 침략 & 방어 (Invasion & Defense)

**침략 발생 조건**:
1. 다른 플레이어가 300m 이내 진입
2. 진지에 접근 (100m 이내)
3. 침략 신호 발동

**침략 진행**:
```
침입자 감지
    ↓ (진지 알림)
터렛 자동 사격
    ↓
침입자 vs 터렛 전투
    ↓
[침입자 승리] → 진지 파괴 → 에테르 약탈 (50%)
[방어 승리] → 침입자 추방 → 경험치 획득
```

**침략자 침입 경로**:
- 추출기 메시 내부에 진입 → 다이렉트 공격
- 또는 터렛 사정거리 밖에서 원거리 공격

## 4. 공식과 균형 (Formulas)

### 4.1 에테르 수집

```
에테르_수집량 = 기본_수집률 × (1 + 강화_보너스) × 시간_초
             = 10 × (1 + 0.1×강화_레벨) × delta
             
예시:
기본: 10/초
레벨 1 강화: 11/초
레벨 5 강화: 15/초
```

### 4.2 터렛 대미지

```
터렛_대미지 = 기본_대미지 × 정확도 × 거리_감소_계수
           = 25 × 0.9 × (1 - 거리/최대_범위)

예시:
반경 0m (직사): 25 × 0.9 = 22.5
반경 25m: 22.5 × 0.5 = 11.25
반경 50m (경계): 22.5 × 0 ≈ 0 (사격 안함)
```

### 4.3 진지 HP

```
진지_총_HP = 기본_HP + (강화_레벨 × 강화_효과)
          = 100 + (강화_레벨 × 20)

예시:
무강화: 100 HP
레벨 5 강화: 100 + 100 = 200 HP
```

### 4.4 침략 보상

```
침입자_보상_에테르 = 피해_진지_에테르 × 0.5
방어자_페널티 = 피해_진지_에테르 × 0.5

예시:
진지에 에테르 1000 저장
침입 성공 시:
  - 침입자 획득: 500 에테르
  - 방어자 손실: 500 에테르
```

## 5. 엣지 케이스 (Edge Cases)

| 상황 | 처리 |
|------|------|
| 진지 HP = 0 | 추출기 파괴, 영토 반납 (다시 vacant) |
| 에너지 부족 (터렛) | 터렛 비활성화 (수동 재활성화 필요) |
| 여러 플레이어 동시 침략 | 먼저 온 플레이어부터 처리, 나머지는 대기 |
| 강화 중 침략 | 강화 즉시 중단, 에테르 환급 |
| 네트워크 끊김 | 로컬 방어 모드 (오프라인 방어) |
| 진지 이동 가능? | 불가능 (설치 후 고정) |
| 다른 플레이어 진지 위에 설치? | 불가능 (충돌 감지) |

## 10. 게임플레이 예시

### 초기 진지 구축 (게임 처음 30분)

```
0분: 게임 시작
  └─ 근처 몬스터 × 3 제거

15분: 첫 추출기 설치
  ├─ 에테르 축적 시작 (10/초)
  └─ 15분 × 60초 × 10 = 9000 에테르 수집

30분: 터렛 배치 + 강화
  ├─ 터렛 배치: 500 × 2 = 1000 에테르
  ├─ 에테르 수집 강화: 1000 에테르
  └─ 남은 에테르: 6000
```

### 침략 시나리오

```
상황:
  - 플레이어A: 진지 HP 100, 터렛 2개, 에테르 5000
  - 플레이어B: 침략 의도, 원거리 사격

침략 과정:
  1. 플레이어B 300m 이내 진입 → 진지 알림
  2. 플레이어B 100m 진입 → 터렛 사격 개시
  3. 터렛: 25 대미지 × 2 = 50 대미지/2초
  4. 플레이어B 투사체 반격: 20 대미지/발
  
결과 (가정):
  - 5초 전투: 터렛 -0, B -60 대미지
  - 플레이어B 격추: 진지 안전, 에테르 유지
  - 플레이어B는 침략 실패, 다른 진지 시도
```
