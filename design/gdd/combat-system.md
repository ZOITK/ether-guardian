## 1. 개요 (Overview)

**전투 시스템**은 게임의 **핵심 상호작용**입니다. 플레이어가 AR 카메라를 통해 현실 공간의 몬스터를 **투사체 무기**로 사냥합니다. 몬스터는 독립적 AI를 가진 적으로 현실 공간의 물리 환경에 배치되며, 충돌과 대미지 계산이 정확하게 일어나야 합니다.

**핵심 루프**:
```
몬스터 스폰 (평면 위)
    ↓
몬스터 AI 이동/공격
    ↓
플레이어 조준 & 발사
    ↓
투사체 물리 & 충돌
    ↓
대미지 계산
    ↓
몬스터 제거 (정화)
```

---

## 2. 플레이어 판타지 (Player Fantasy)

- **정확한 조준의 쾌감**: 카메라 기울기로 몬스터를 조준하고, 터치로 발사
- **물리 기반 투사체**: 중력을 받는 현실감 있는 투사체 궤적
- **전술적 사냥**: 몬스터 이동을 예측하고, 벽 뒤로 숨는 적을 추적
- **점진적 난이도**: 초반 느린 몬스터 → 후반 빠르고 강한 적
- **즉각적 피드백**: 명중 시 분명한 대미지, 효과음, 파티클

## 3. 상세 규칙 (Detailed Rules)

### 3.1 몬스터 타입

**타입 1: 슬라임 (Slime) — 약함**
- HP: 20
- 이동 속도: 2 m/s
- 행동: 플레이어 방향으로 천천히 접근
- 공격: 접근 후 1초마다 재생성 (복제)
- 대미지: 없음 (접촉 시 플레이어 밀침)
- 스폰: 중복 스폰 최대 3개

**타입 2: 드론 (Drone) — 중간**
- HP: 50
- 이동 속도: 4 m/s
- 행동: 플레이어를 추적, 원을 그리며 회전
- 공격: 1초마다 에너지 빔 발사
- 대미지: 10 (직중 시)
- 스폰: 동시 최대 2개

**타입 3: 타이탄 (Titan) — 강함**
- HP: 150
- 이동 속도: 3 m/s
- 행동: 느리지만 집요한 추격
- 공격: 5초마다 범위 폭발 (반경 10m)
- 대미지: 25 (범위)
- 스폰: 동시 최대 1개 (보스급)

### 3.2 몬스터 AI (의사코드)

```gdscript
# 상태 머신
enum AIState { IDLE, PATROL, CHASE, ATTACK, DIE }

func _process_ai(delta: float):
    match current_state:
        AIState.IDLE:
            # 1. 플레이어 감지 범위 내 있는가?
            if player_in_detection_range(50.0):
                current_state = AIState.CHASE
        
        AIState.CHASE:
            # 2. 플레이어 방향으로 이동
            var direction = (player.position - position).normalized()
            velocity = direction * movement_speed
            position += velocity * delta
            
            # 3. 플레이어 접근?
            if player_in_range(attack_range):
                current_state = AIState.ATTACK
        
        AIState.ATTACK:
            # 4. 공격 (타입별로 다름)
            if attack_cooldown <= 0:
                execute_attack()
                attack_cooldown = attack_interval
            
            attack_cooldown -= delta
            
            # 5. 플레이어 거리?
            if not player_in_range(chase_range):
                current_state = AIState.IDLE
        
        AIState.DIE:
            # 6. 제거 및 정화
            die()

func execute_attack():
    match monster_type:
        "slime":
            spawn_clone()  # 복제
        "drone":
            fire_energy_beam(player.position)  # 빔 발사
        "titan":
            explosion_damage(position, 10.0)  # 범위 폭발
```

### 3.3 투사체 시스템 (Projectile System)

**투사체 초기화**:
```
발사 위치: 카메라 위치 (머즐)
발사 방향: 카메라 look-at 벡터
초기 속도: 20 m/s
중력 가속도: 9.8 m/s² (현실 물리)
```

**투사체 물리**:
```gdscript
func _process_projectile(delta: float):
    # 1. 중력 적용
    velocity.y -= gravity * delta  # 9.8 m/s²
    
    # 2. 위치 업데이트
    position += velocity * delta
    
    # 3. 수명 제한 (맵 벗어남 방지)
    lifetime -= delta
    if lifetime <= 0:
        projectile.queue_free()  # 자동 제거
    
    # 4. 충돌 감지 (Raycast3D)
    var collision = check_collision(position, velocity * delta)
    if collision:
        handle_collision(collision)

func handle_collision(hit_target):
    match hit_target.type:
        "monster":
            hit_target.take_damage(projectile_damage)
            hit_target.apply_knockback(velocity)
        "wall":
            riccochet(velocity)  # 벽에 튕김
        "extractor":
            damage_extractor(20)
    
    projectile.queue_free()
```

**발사 조건**:
- 카메라가 고정 → 발사 지점은 머즐 (카메라 앞 30cm)
- 연사 쿨다운: 0.3초 (초당 3발)
- 최대 동시 투사체: 30개 (성능 제한)

### 3.4 대미지 계산 (Damage)

**기본 대미지**:
```
투사체_대미지 = 기본_대미지 × 거리_감소 × 크리티컬_배수
             = 30 × (1 - 거리/최대_거리) × 크리티컬
```

**거리 감소 곡선**:
```
0m (직사): 100% → 30 대미지
10m: 66% → 20 대미지
20m: 33% → 10 대미지
30m+ (최대): 0% → 무시
```

**크리티컬 히트**:
- 확률: 15%
- 배수: 1.5x
- 효과음: 특별한 음향

### 3.5 상태이상 (Status Effects)

**타입**:
- **스턴**: 2초 이동 불가 (Drone 공격 히트 시)
- **서방**: 이동 속도 50% 감소, 3초 지속 (Slime 독 접촉)
- **화상**: 초당 2 대미지, 5초 지속 (Titan 폭발)

## 4. 공식과 균형 (Formulas)

### 4.1 몬스터 HP와 플레이어 대미지 밸런스

```
적중 필요 횟수 = 몬스터_HP / 투사체_대미지

슬라임:
  HP 20 / 30 대미지 = 0.67 발 ≈ 1발 필요

드론:
  HP 50 / 30 대미지 = 1.67 발 ≈ 2발 필요

타이탄:
  HP 150 / 30 대미지 = 5발 필요
```

### 4.2 각 타입별 위협도 (Threat Level)

```
위협도 = (HP + (이동속도 × 10) + (공격력 × 5)) / 100

슬라임: (20 + 20 + 0) / 100 = 0.4 (약함)
드론: (50 + 40 + 50) / 100 = 1.4 (중간)
타이탄: (150 + 30 + 125) / 100 = 3.05 (강함)
```

### 4.3 스폰 난이도 조정

```
플레이어_평균_피해 = 30 × 정확도(80%)
               = 24 대미지/발

스폰_간격 = 기본_간격 × (1 - 플레이어_진행도 × 0.1)
         = 30초 × (1 - 진행도)

예시:
초기: 30초 (쉬움)
중반(50% 진행): 15초 (중간)
후반(100% 진행): 0초 (매우 어려움, 즉시 스폰)
```

## 5. 엣지 케이스 (Edge Cases)

| 상황 | 처리 |
|------|------|
| 벽 너머 몬스터 | 렌더링 X, 공격 방지 (오클루전) |
| 동시 다중 투사체 충돌 | 각각 대미지 적용 (중첩 가능) |
| 몬스터가 진지 도달 | 진지 접촉 시 자동 제거 (오염) |
| 투사체 최대값 초과 | 가장 오래된 투사체부터 제거 |
| 지면 아래 몬스터 스폰 | 감지된 평면 위로 자동 배치 |
| 플레이어 건물 벽 통과 | 벽에 막힘 (물리 충돌) |
| 슬라임 무한 복제 | 최대 3개 제한 |

## 10. 게임플레이 예시

### 초급 진행 (처음 5분)

```
1분: 슬라임 × 2 스폰
  └─ 천천히 접근 (2 m/s)
  └─ 플레이어 1발씩 사격으로 제거

3분: 드론 스폰
  ├─ 원을 그리며 회전, 빔 발사
  ├─ 플레이어 조준 + 2발 발사
  └─ 드론 제거

5분: 슬라임 × 3 + 드론 × 1
  └─ 어려움 증가
```

### 중급 진행 (10-15분)

```
10분: 타이탄 첫 스폰
  ├─ 느리지만 강력 (HP 150)
  ├─ 5발 필요 (연사 쿨다운 0.3초 = 1.5초 소요)
  └─ 플레이어 우회 이동으로 조준 시간 확보

15분: 동시 다중 몬스터 (타이탄 1 + 드론 2 + 슬라임 3)
  ├─ 우선순위: 타이탄 > 드론 > 슬라임
  └─ 전술적 조준 필요
```
