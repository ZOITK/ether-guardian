# 에테르 가디언 (Ether Guardian) — 게임 컨셉

**작성일**: 2026-04-15  
**최종 수정**: 2026-05-21  
**상태**: 확정

---

## 1. 개요 (Overview)

현실 세계 위에 겹쳐진 또 다른 차원 '에테르 월드'의 균열이 발생했습니다. 플레이어는 **가디언(Guardian)**이 되어 AR 카메라를 통해 현실 공간을 침식하는 **차원 몬스터를 사냥**하고, 정화된 지역에 **에테르 추출기**를 설치하여 **영토를 점유**합니다.

**핵심 메시지**: "경계 없는 세상에서, 당신의 진지만이 당신이다."

---

## 2. 플레이어 판타지 (Player Fantasy)

- **생존자의 역할**: 무너진 세상에서 혼자가 아니면서도 혼자여야 한다는 긴장감
- **영토 확보의 쾌감**: 정화한 지역을 나의 것으로 표시하고, 방어하는 성취감
- **PvE + PvP의 균형**: 몬스터와 싸우면서 동시에 다른 플레이어의 침략을 대비
- **진화하는 감정 호 (Emotional Arc)**:
  - 초반: "우리 함께 살아남자"
  - 중반: "저 사람... 언제 내 것을 가져갈까?"
  - 후반: "나 아니면 저놈. 선택지는 없다."

## 3. 상세 규칙 (Detailed Rules)

### 3.1 세계관: 디지털 시뮬레이션

당신이 살던 세상은 거대한 디지털 시뮬레이션 **'에테르 월드(Ether World)'**였습니다.

**3개월 전, 재앙 시작**:
- 에테르 월드의 기반이 되는 차원 경계에 거대한 균열(Rift) 발생
- 균열에서 **제어 불능의 몬스터**들이 흘러나옴
- 세상이 점진적으로 붕괴 (건물 소실, 시간/공간 왜곡, 중력 이상)

**결과**:
- 정부 시스템 무너짐
- 국가가 없던 시대로 복귀 (단, 디지털 무기 보유)
- 생존 경쟁 시작

### 3.2 핵심 루프 (4단계)

```
1. 스캔 (Scan)
   └─ AR 카메라로 주변 지형(바닥, 벽) 인식
      실시간 평면 감지 → 3D 메싱

2. 사냥 (Hunt)
   └─ 3D 공간에 배치된 몬스터를 원거리 투사체로 제거
      투사체 물리 + 충돌 감지

3. 점유 (Claim)
   └─ 몬스터 제거 지점에 '에테르 추출기' 설치
      GPS 기반 영토 소유권 기록

4. 방어 (Defend)
   └─ 점유한 영토에 자동 방어 터렛 배치
      다른 플레이어 침입 대비
```

### 3.3 에테르 추출기 (Ether Extractor)

- **역할**: 주변 에테르 자동 수집, 에너지 생성
- **기능**:
  - 수동 방어 터렛 배치 가능
  - 자동 방어 (플레이어 침입 시)
  - 다른 가디언의 침략 저항
- **생명선**: 이것이 당신의 유일한 안식처

### 3.4 갈등 구조 (The Core Conflict)

모든 자원은 **유한**합니다:

**외부 위협** (PvE):
- 몬스터들의 무작위 습격
- 균열의 확산 (결국 전 지역 포함)

**내부 위협** (PvP):
- 다른 가디언들의 영토 침략
- 자신의 진지 약탈
- 동맹과 배신의 반복

**생존의 역설**:
```
강한 진지를 만든다
    → 다른 가디언들의 표적이 된다
       → 더욱 강해져야 한다
          → 더욱 많은 적을 만든다
```

**결론**: "당신은 혼자가 아니면 안 되는데, 혼자가 아니면 죽는다."

## 4. 공식과 균형 (Formulas)

### 에테르 추출 속도
```
에테르_수집량 = 기본_수집률 × 영토_면적 × (1 + 업그레이드_보너스)
             = 10 에테르/초 × 100m² × (1 + 0.2)
             = 1,200 에테르/초
```

### 방어 터렛 화력
```
터렛_대미지 = 기본_대미지 × (1 + 정확도_보정) × 타겟_거리_감소
           = 25 × (1 + 0.9) × 거리계수
```

### 플레이어 침입 감지 범위
```
감지_범위 = 추출기_위치로부터_500m
(GPS 기반, 실시간 업데이트)
```

## 5. 엣지 케이스 (Edge Cases)

| 상황 | 처리 |
|------|------|
| 균열 영역에 진지 설치 | 불가 (게임 영역 제한) |
| 다른 플레이어 진지 위에 설치 시도 | 충돌 감지 후 실패 |
| 네트워크 연결 끊김 | 로컬 모드 전환 (오프라인 PvE만) |
| 터렛 에너지 고갈 | 자동 비활성화 (수동 재활성화 필요) |
| 몬스터가 터렛을 파괴 | 현지 재구축 필요 (에테르 소비) |

## 6. 의존성 (Dependencies)

- **영상 처리 시스템**: ARCore/ARKit 평면 감지
- **물리 엔진**: Godot 3D 물리 (Rigidbody, Raycast)
- **네트워크**: Go 소켓 서버 (플레이어 위치, 영토 데이터 동기화)
- **위치 서비스**: GPS (지오스페이셜 API)
- **UI/HUD**: 실시간 성능 모니터링, 영토 지도

---

## 7. 튜닝 노브 (Tuning Knobs)

| 파라미터 | 기본값 | 범위 | 영향 |
|---------|-------|------|------|
| 몬스터 스폰 간격 | 30초 | 15-60초 | 난이도 |
| 에테르 수집률 | 10/초 | 5-20/초 | 진행 속도 |
| 터렛 쿨다운 | 2초 | 1-5초 | 방어력 |
| 침입 감지 범위 | 500m | 300-800m | PvP 빈도 |
| 배터리 소비 | 높음 | 낮음-높음 | 세션 길이 |

---

## 8. 수용 기준 (Acceptance Criteria)

- ✅ AR 평면 감지 정확도 >85%
- ✅ 몬스터 AI 기본 로직 (이동, 공격 패턴)
- ✅ 투사체 물리 + 충돌 감지 구현
- ✅ 영토 점유 로직 (GPS 기반 위치 기록)
- ✅ 기본 PvP 침입/방어 시스템
- ✅ Go 백엔드 (플레이어 위치 동기화)
- ✅ 모바일 60FPS 유지 (고성능 기기)
- ✅ 배터리 세션 30분 이상

## 9. 장기 비전 (Long-Term Vision)

### 시즌 1 (프로토타입 / 수직 슬라이스)
- 생존 중심의 PvE + PvP
- 작은 스케일의 영토 전쟁
- 몬스터 정체에 대한 단서 수집

### 시즌 2 (확장)
- 진영 전쟁 (3~4개 진영 간의 대규모 충돌)
- 에테르 월드의 기원 규명
- 플레이어의 선택이 세상을 바꾼다 (분기 내러티브)

### 시즌 3 (최종)
- "균열 너머로" — 디지털 세상 탈출 가능한가?
- 또는 더 큰 멀티버스의 발견
